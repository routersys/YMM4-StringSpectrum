# 弦の振動 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)

---

YukkuriMovieMaker4（YMM4）上で動作する、音声に合わせて弦が振動する形を描く波形プラグインです。
低い周波数帯を 1 次、その上を 2 次と、両端を固定した弦の振動モードへ順に割り当て、重ね合わせた形を一本の線で描きます。
n 次のモードは基本振動数の n 倍で振動するため、同じ音が続いても形は時間とともに変わります。

## 概要

本プラグインは YMM4 の図形アイテムの波形として動作します。「波形の種類」に「弦の振動」として表示されます。YMM4 から受け取った周波数帯ごとの値を、低い帯から順に 1 次、2 次、3 次の振動モードへ割り当てます。各モードは両端を固定した弦の形で、n 次のモードは弦を n 等分する節を持ちます。すべてのモードを重ね合わせた形を、一本の線として描きます。

弦は図形の中央を原点にして左右へ伸び、両端は固定されて動きません。帯の値が大きいモードほど大きく振れ、全体の振れは「振幅」を超えません。

モードの重みは CPU で求め、弦の形と線の描画は GPU のピクセルシェーダーで行います。設定は図形アイテムの波形の項目としてプロジェクトに保存します。プラグイン自体の設定ファイルはありません。

画面の表示は日本語のほか、英語、簡体字と繁体字の中国語、韓国語、スペイン語、アラビア語、インドネシア語に対応します。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-StringSpectrum/releases/latest) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4 を起動し、図形アイテムの「種類」を「波形」にして、「波形 / 描画」にある「波形の種類」で「弦の振動」を選びます。
4. 既定の設定では、長さ 600px の弦が中心線から 120px まで振れ、1 次のモードが 1 秒に 1.2 回往復します。「振幅」と「モードの数」で見た目を調整します。

## 主な機能

### 1. 弦の形

「弦の長さ」は、固定した両端の間の距離です。弦は図形の中央を原点にして、左右へ半分ずつ伸びます。

「モードの数」は、重ね合わせるモードの上限です。実際に重ね合わせる数は、受け取った帯の数と、「モードの数」と、弦の長さの画素数を 3 で割って切り捨てた数のうち、いちばん小さいものです。低い帯ほどゆるやかな波を作り、高い帯ほど細かい波を作ります。

「振幅」は、弦が中心線から離れる最大の距離です。各モードの振れは帯の値に比例します。重ね合わせるときは、各帯の値を、実際に重ね合わせる数の平方根で割ります。帯の値の絶対値の合計がその平方根を超えるときは、代わりにその合計で割ります。重ね合わせた値に「振幅」を掛けた距離だけ、弦は中心線から離れます。そのため、どれほど大きな音でも弦の振れは「振幅」を超えません。

受け取った値が負のときは、反対の向きへ振れます。値は -1 から 1 の範囲に収めてから使います。

### 2. 時間による変化

「基本振動数」は、1 次のモードが 1 秒に往復する回数です。n 次のモードは n 倍の速さで往復するため、同じ音が続いても弦の形は時間とともに変わります。0 にすると形は止まり、負の値は同じ大きさの正の値と同じ動きになります。

往復の位置は、アイテムの先頭から数えた時刻で決まり、描画の回数や描いた時刻には左右されません。同じフレームは何度描いても同じ形になります。

### 3. 線の描き方

「線の太さ」は、線の幅です。太さは線に垂直な方向で測るため、弦が急に傾く場所でも線は細くなりません。線の縁は、内側 1px から外側 1px にかけてなめらかに透明へ変わります。線の太さが 2px より細いときは、線の中心から外側 1px にかけて変わります。

「色」は、線の色です。不透明度を下げると、線は半透明になります。

### 4. 出力の範囲

図形の出力範囲は、弦と線の縁が収まる大きさに毎フレーム合わせます。横は「弦の長さ」の半分に 1px を足した分だけ、中央から左右へ広げます。縦は次の式の分だけ、中央から上下へ広げます。

`振幅 + (線の太さ / 2 + 2) × √(1 + (振幅 × π × 重ね合わせるモードの数 / 弦の長さ)²)`

傾きが急な場所では線が縦に長く見えるため、最も急な傾きを見込んで範囲を取り、線が途中で切れないようにしています。

## パラメータ一覧

| 項目 | 既定値 | 内容 |
|---|---|---|
| 弦の長さ | 600px | 固定した両端の間の距離です。0.01px から 100000px までです。 |
| 振幅 | 120px | 弦が中心線から離れる最大の距離です。0px から 100000px までで、0px にすると直線になります。 |
| 基本振動数 | 1.2 | 1 次のモードが 1 秒に往復する回数です。-100000 から 100000 までで、0 にすると形が止まります。 |
| モードの数 | 24 | 重ね合わせるモードの上限です。1 から 64 までの整数です。 |
| 線の太さ | 3px | 線の幅です。0.01px から 100000px までです。 |
| 色 | 白 | 線の色です。不透明度を含みます。 |

「弦の長さ」「振幅」「基本振動数」「線の太さ」は、YMM4 のアニメーションの設定で時間に沿って変えられます。「モードの数」と「色」はアニメーションできません。

---

## 制限事項

- 描くのは一本の線だけです。塗りつぶしや複数の弦は描けません。
- 重ね合わせるモードは 64 個までです。帯の数が 64 を超えるときは 64 個の区間に分け、各区間で絶対値がいちばん大きい値を使います。
- 弦が短いと、使えるモードの数が減ります。弦の長さ 3px につき 1 個が上限で、弦がどれほど短くても上限は 1 個を下回りません。
- AviUtl の exo ファイルへの書き出しには対応していません。

## 注意事項

- 更新の確認: 図形の「波形の種類」を「弦の振動」にするか、弦の振動を含むプロジェクトを開いたときに、YMM4 の起動ごとに一度だけ GitHub のリリースを確認し、新しいものがあればメッセージで知らせます。
- 不具合の自動送信: 想定していない例外が起きたときは、その内容を開発者へ自動で送信します。内容は「不具合の報告」に書いています。
- 本プラグインを使用する前に、YMM4 プロジェクトファイルのバックアップを作成することを推奨します。

## 不具合の報告

本プラグインは、想定していない例外が起きたときに、その内容を開発者へ自動で送信します。同意は求めず、常に送信します。

送信する情報は次のとおりです。

| 種類 | 内容 |
|---|---|
| 例外 | 型の完全名、メッセージ、スタックトレース |
| 発生位置 | モジュール名、関数名、ファイル名、行番号 |
| プラグイン | アセンブリ名、バージョン |
| 実行環境 | OS の名前とバージョン、.NET のバージョン、CPU のアーキテクチャ、論理プロセッサ数 |
| 識別子 | YMM4 の起動ごとに決まるセッション識別子、報告ごとの識別子 |

メッセージとファイル名は、送信の前に置き換えを通します。置き換えるのは、Windows のユーザー名、ユーザーフォルダー、AppData のパス、マシン名、ドメイン名、メールアドレス、IPv4 アドレスです。送信元の IP アドレスは受信側へ渡す手前で取り除いています。

音声の内容、映像の中身、プロジェクトの内容は送信しません。継続して個人を追跡する識別子も持ちません。セッション識別子は YMM4 を起動し直すと別の値になります。

送信するのは想定していない例外だけです。YMM4 が本プラグインの波形の設定を作るとき、描画を準備するとき、フレームごとに更新するとき、破棄するときと、Direct2D がシェーダーの定数を書き込むときに起きた例外を報告し、その後は YMM4 へそのまま渡します。画面の操作やバックグラウンドの処理で未処理になった例外も報告しますが、本プラグインのコードが関わる例外に限ります。本プラグインの外で起きた例外は送信しません。

次の失敗は送信しません。

| 種類 | 例 |
|---|---|
| 何も描かないだけで済ませるもの | Direct2D がエフェクトを作れず、弦を描かなかったとき |
| 更新の確認の通信の失敗 | GitHub へ接続できない |

送信できなかった報告は YMM4 のユーザーフォルダーへ退避し、次回の起動時に送り直します。送信も再送も非同期に行うため、起動と描画が遅くなることはありません。

実装は [YMM4-Telemetry](https://github.com/routersys/YMM4-Telemetry) をサブモジュールとして取り込んでいます。
